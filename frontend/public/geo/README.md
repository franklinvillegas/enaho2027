# Límites departamentales del Perú

`peru_departamentos.geojson` proviene de https://github.com/juaneladio/peru-geojson
(archivo `peru_departamental_simple.geojson`), con licencia Mozilla Public License 2.0
(ver `LICENSE-peru-geojson.txt`). Fuente original de los límites: INEI-2007.

Se usa para el mapa de calor por departamento. Se sirve como archivo estático, sin
depender de servicios externos (el sistema actual usaba Google GeoChart con una clave
de API expuesta en el JavaScript).
